# Ethan Chigodo — CV companion

Five accessible static pages accompanying Ethan's PDF CV. Published from main with GitHub Pages.

## Editing

Edit the relevant HTML page directly on GitHub. Each page includes its complete styles in `<style>` to prevent an older cached stylesheet from breaking a new layout. Apply shared header, navigation, sidebar, and style changes consistently across all five pages.

- index.html — overview
- education.html — education and qualifications
- sports.html — sport
- activities.html — leadership
- volunteering.html — community service

The EC monogram reserves space for a real portrait. Replace the `.portrait` content with an image with meaningful alt text when a portrait is supplied. Do not use a stock portrait.

The public site excludes scans, identification numbers, and private attachments. The robots metadata requests no indexing; this is not access control. The PDF is shared directly by Ethan and is not hosted here.

Verify desktop and mobile layouts, navigation, disclosures, and print preview after editing. No build step, scripts, external fonts, or runtime dependencies are required (the print button uses the browser's print function).
